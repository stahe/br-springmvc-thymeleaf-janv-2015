# Introdução ao Spring MVC e ao Thymeleaf

👉 **Acesse o curso online**:  
https://stahe.github.io/br-springmvc-thymeleaf-janv-2015/

## Visão geral

Este documento tem como objetivo apresentar, por meio de exemplos, os conceitos básicos do **Spring MVC**, uma estrutura web em Java baseada no **modelo MVC (Model – View – Controller)**.

O Spring MVC faz parte do ecossistema do **Spring Framework** e oferece uma estrutura para o desenvolvimento de aplicações web em Java robustas e fáceis de manter.

O curso também aborda o **Thymeleaf**, um mecanismo de visualização moderno e poderoso que está muito bem integrado ao Spring MVC.

## Público-alvo

Este curso destina-se a leitores com **bom domínio da linguagem de programação Java**.

**Não é necessário ter conhecimento de programação web**, uma vez que os conceitos são apresentados passo a passo.

## Escopo do documento

Embora este documento seja bastante detalhado, ele não pretende ser exaustivo.  
O Spring é um framework abrangente, composto por inúmeros componentes e extensões.

O documento foi elaborado de forma a poder ser lido **sem computador**, o que explica a presença de inúmeras **capturas de tela**.
